## 1. 背景与业务定位

采集期（PRJ-0001）已把接口沉淀为结构化卡片，但卡片只是静态文档。要"跑起来"，首先需要一个**机器可消费的流程载体**——链（chain）。本需求定义链的数据契约，是第二期其余 5 条需求（画布、执行、换票、首跑、结晶复跑）的共同地基。

**一句话业务定义**：编排者把接口库里的接口卡按"谁的出参喂谁的入参"连起来，形成一份可存取、可版本化、可导入导出的链文件。

**边界**：本需求只交付数据契约与存取——不含画布 UI（R-2）、不含执行（R-3）。agent 手写链文件也应能造出合法链。

## 2. 业务目标与价值

| # | 目标 | 衡量方式 |
|---|---|---|
| G1 | 链是显式的数据契约，不依附任何编辑器 | 手写链文件（不经画布）通过校验即为合法链 |
| G2 | 绑定即依赖：边 = "下游入参 ← 上游出参"的显式声明 | 从链文件可机械推出拓扑序，无需额外依赖声明 |
| G3 | 坏定义在定义期就被拒，不留到执行期爆炸 | 悬空引用/成环/绑定字段不存在均有明确中文错误 |
| G4 | 链可演进、可追溯 | 同一流程多版本共存，可回读任意版本快照 |

## 3. 角色与使用场景

| 角色 | 说明 |
|---|---|
| 编排者（人或 agent） | 定义链：选卡、连线、声明绑定 |
| 执行引擎 | 消费链文件（R-3 起），要求契约稳定 |

**典型场景**：

1. **S1 手工编排**：agent 根据用户口述的"先查材料、再查价格、再建订单"，从接口库选 3 张卡写成链文件，声明两条绑定边。
2. **S2 版本演进**：流程调整后另存 v2，v1 快照仍可回读、可导出。
3. **S3 导入导出**：链文件导出给另一个项目/工作区导入使用。

## 4. 功能需求

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-1.0 | 接口库导入：capture SQLite 卡片导入项目接口库，跨 run 同接口归并、分配项目内稳定卡 ID、保留来源溯源（captureId/页面包） | P0 |
| FR-1.1 | 链文件格式定稿：**YAML**（已决 2026-10-17，与流程包同款生态）；声明式描述 meta/inputs/nodes/edges | P0 |
| FR-1.2 | 节点 = 接口卡引用 + 节点级配置（重试、超时等预留位） | P0 |

| FR-1.4 | 定义期校验：悬空卡引用、成环、绑定字段在卡模板中不存在、入参槽位未声明——逐一明确报错 | P0 |
| FR-1.5 | 版本快照：流程下多版本共存，版本为不可变快照 | P1 |
| FR-1.6 | 导入导出：链文件整进整出，导出不含任何凭证信息 | P0 |
| FR-1.7 | 入参槽位声明：链级 inputs（如"材料编码"），供 R-6 结晶复跑替换 | P0 |

## 5. 接口卡引用身份（已决）

**决策（2026-10-17）**：先做"采集包导入项目接口库"，节点用项目内稳定 ID 引用卡片。导入时跨 run 归并同接口（merge_key 一致即同卡），链不因重新采集而失效；直接引用 `(capture_id, merge_key)` 被否——重新采集产生新卡会导致旧链引用悬空。

因此本需求范围包含一个前置子能力：**接口库导入**（capture SQLite → 项目接口库，含来源溯源），它同时是 PRJ-0001 §10 下期展望的首项。

## 6. 验收判据

- 给定采集期真实接口库，先导入为项目接口库（同接口跨 run 归并为一张卡、带来源溯源），再定义一条 ≥3 节点、含绑定边的链并落盘；
- 悬空引用、成环、绑定字段不存在三类坏定义分别被拒，错误信息指到具体节点/边；
- 同一流程两版本共存，可回读各自快照；
- 导出的链文件在干净工作区导入后校验通过。

## 7. 依赖与不做

- **依赖**：PRJ-0001 接口库（卡片与字段模板已落库）。
- **不做**：画布 UI（R-2）；任何执行语义（R-3）；条件边/审批分支（本期明确延期）。

## 8. 决策记录与开放问题

| 问题 | 选项 | 结论 |
|---|---|---|
| Q1 链文件格式 | YAML / JSON | **已决（2026-10-17）：YAML**——人可读可手改，与流程包同款生态 |
| Q2 页面编排与接口编排的关系 | 编译 / 独立执行模型 | **已决（2026-10-17）：页面编排编译为接口编排后执行**——执行模型只有一套（HTTP 直调），守住"浏览器只在采集段"的边界 |
| Q3 接口卡引用身份 | 直接引用 / 导入后稳定 ID | **已决（2026-10-17）：先导入项目接口库用稳定 ID**（见 §5） |
